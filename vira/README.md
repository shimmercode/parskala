# ویرا ۱.۰.۱ — قالب فروشگاهی بدون دکان

## نصب
1. پوشه `vira` را در `wp-content/themes/vira` کپی کنید (نه کل ریپو).
2. وردپرس ۶.۴+ و PHP ۷.۴+ و **ووکامرس** را فعال کنید.
3. ظاهر → پوسته‌ها → ویرا را فعال کنید.
4. پیشخوان → قالب ویرا → ماژول‌ها را ذخیره کنید.

## چه چیزی درست شد
- کرش `add_meta_box()` در بوت وردپرس
- لود نشدن فایل‌های ionCube / پارس‌کالا در `functions.php`
- حذف دکان از قالب
- ۲۹ ماژول با `class-controller.php` واقعی
- قالب‌های ووکامرس بدون توابع تعریف‌نشدهٔ پارس‌کالا

## OTP
تا وقتی کلید API پیامک در مرکز فرماندهی تنظیم نشود، ارسال کد خطا می‌دهد (عمدی، تا کد جعلی ساخته نشود).
